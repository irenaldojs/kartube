# Assets externos — área reservada

A estrutura abaixo existe para a **futura** entrada de conteúdo; nenhum asset de jogo foi fornecido nem criado nesta etapa.

- `personagens/`: pilotos, skeletons, texturas, skins.
- `karts/`: veículos, rodas, variantes, colisores de referência.
- `pistas/`: malhas, módulos de cenário e materiais.
- `powerups/`: itens e caixas de coleta.
- `efeitos/`: partículas, sprites, materiais de efeitos.
- `audio/`: música, efeitos e feedback de UI.
- `interface/`: ícones, imagens e fontes.
- `referencias/`: referências de produção com direitos comprovados.

**Antes de adicionar:** verificar licença/origem, uso comercial, consentimento de pessoas identificáveis, atribuição, otimização e ID no manifesto. Para influenciadores, não publicar referências, nomes ou modelos sem autorização. Documentação completa: [`docs/10-personagens-e-assets.md`](../docs/10-personagens-e-assets.md).
